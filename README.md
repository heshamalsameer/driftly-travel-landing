# driftly — Travel landing page

“Travel now · feel natural” — an editorial, scroll-driven travel landing page.

**Stack:** React 18 · Vite · Tailwind CSS 3 · react-icons

### Sections
- **Hero window** – the video starts inside a rounded window and opens to full screen as you scroll (videos cross-fade)
- **Boarding-pass search** – destination, date and travellers with a live price estimate
- **Destinations** – pinned horizontal scroll on desktop, swipe on mobile, with hand-drawn SVG postcards (no stock photos)
- **Mood picker** – choose how you want to feel and get matching trips
- **Stats marquee**, **journey route** that draws itself on scroll
- **Polaroid stories** you can shuffle, **luggage-tag pricing** with solo / duo toggle
- **Postcard newsletter** and a footer with live world clocks

```bash
npm install
npm run dev     # http://localhost:3000
npm run build
```
